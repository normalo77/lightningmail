=== WordPress Readme ===
== Description ==
"Sign in with lightningmail" button (passwortloser OIDC-Login).
== Installation ==
Plugins -> Hochladen -> lightningmail-login.zip. Danach Einstellungen -> lightningmail Login.
== Notes ==
Der Server prueft das ID-Token gegen das Relay-JWKS (ES256, eigene Route im Plugin). Kein Client-Secret.
